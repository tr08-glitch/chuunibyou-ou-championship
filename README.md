# 厨二王選手権

漢字のお題に横文字を考えて、一番しっくりきてかっこいい回答に投票するオンラインパーティゲームです(3〜8人)。

## 遊び方
1. お題(漢字3〜6文字)が出る。全員が横文字を考えて提出(例:地獄業火 → ヘルファイア)
2. **発表**: 全員が出し終えたら、1人ずつ名前つきで回答を公開していく(1人6秒。ホストの「次の発表へ」で早送り)。声やチャットで読み上げて盛り上がろう
3. **投票**: 全員の回答が名前つきで並ぶ。自分以外の回答に1票を入れる
4. **結果**: 誰が何票入れたかも公開される
5. これを数ラウンド繰り返し、合計得票が最多の人が優勝(同点は全員優勝)

## 回答方法(手書き / 入力)
回答画面のタブで切り替えられます。初期設定は手書きです(選んだ方法はブラウザに記憶されます)。
- **手書き**: 指やペンで書く。「1つ戻す」「全部消す」あり。画像(PNG)として送信される
- **入力**: 文字を打ち込む(30文字まで)
- 手書きと入力の回答は、同じ投票画面に混ざって表示されます

## 復帰・チャット・通話
- **復帰の確認**: ページを開き直したり回線が切れて戻ったとき、戻れる部屋があれば「ルームに復帰しますか?」と聞きます。「復帰しない」を選ぶとその部屋から退出します
- **チャット**: 画面下の「💬 チャット」。部屋の全員に届き、直近50件が残ります(5秒に5件まで)
- **通話**: 画面下の「📞 通話に参加」で通話に入り(押すと「通話から退出」に変わります)、入ると「🎤 マイクON」ボタンが出ます。マイクボタンを押すとミュート(🔇)、もう一度でミュート解除です。通話中の人は名前の横に🎤が付きます
  - 参加者どうしを直接つなぐ方式(WebRTC)で、音声はサーバーを通りません。8人でも動く想定です
  - マイクの利用には **HTTPS** が必要です(Render などの公開環境はOK。`localhost` もOK)
  - 無料のSTUNサーバーだけを使っているため、会社・学校などの厳しいネットワークでは音声がつながらない場合があります。その場合は TURN サーバーの追加が必要です(`public/index.html` の `ICE` に追記)

## 荒らし対策
- **投票キック**: 画面下の「🚫 キック」から、誰でもキックしたい相手を選んで投票を始められます
  - 全員(対象本人を除く)が30秒以内に「キックする / しない」を投票。始めた人は自動で「キックする」に1票
  - 賛成が投票できる人数の **2/3以上** で可決(未投票は反対扱い)。可決されると即キック、反対が多くて可決できなくなった時点で否決
  - キックされた人は、そのルームに二度と入れません(ブラウザごとのIDで判定)
  - 投票を始められるのは **各自15分に1回**(部屋を移っても共通)。同時に行える投票は1つだけ。3人以上いるときのみ
- **モラルの説明**: ランダムマッチを始めるとき、1日1回(そのブラウザで最初の1回)だけ、マナーの説明を表示します

## 起動
```
npm install
npm start        # http://localhost:3000
npm test         # サーバー起動中に実行(PORT環境変数で接続先ポート変更可)
```

## オンライン入室
- **ルームを作る**: 4文字のルームコードが発行される。友達にコードか招待リンクを送る
- **入室**: コードを入力
- **ランダムマッチ**: 公開ルームに自動で入室。3人以上いると20秒後に自動開始、8人揃えば即開始

## 設定(ロビーでホストが変更)
ラウンド数 / 回答時間 / 投票時間(初期値: 5回 / 60秒 / 30秒)

## お題の単語を変える
`words.js` の `WORDS1`(1文字)、`WORDS2`(2文字)、`WORDS3`(3文字)を編集します。
お題は1〜3語をランダムに組み合わせ、3〜6文字で同じ漢字が重複しないものだけ採用されます。

## Render へのデプロイ
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/healthz`
- 部屋の情報はサーバーのメモリ上にあります。再起動・スリープすると進行中の部屋は消えます。
  無料プランはスリープするため、安定して遊ぶなら常時起動のプランがおすすめです。

## 構成
- `server.js` ルーム管理・マッチング・ゲーム進行(Express + Socket.IO)
- `words.js` 単語リストとお題生成
- `public/index.html` 画面(スマホ対応、素のHTML/JS)
- `test/smoke.js` 擬似クライアント3人のスモークテスト
